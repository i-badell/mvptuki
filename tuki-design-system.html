Tipografía
Tuki usa tres familias tipográficas con roles bien definidos. Nunca se intercambian.
Bebas Neue
--font-display · Títulos, labels, precios, métricas, step indicators
Mi Carrito $1.150 NUEVOS DESGLOSE
Playfair Display
--font-serif · Nombres de trucks y clientes únicamente
Brutal Burger Tate Silveira Lucía Fernández
DM Sans
--font-body · Todo el resto: body, labels, botones, descripciones
Button text — 700 · 16px Item name — 600 · 14px Form label — 500 · 13px Description text — 400 · 12px EYEBROW LABEL — 700 · 10px · UPPERCASE
✓ Correcto

Usá Playfair solo para nombres propios (trucks, clientes). Bebas para datos y estructura. DM Sans para todo el texto de interfaz.

✕ Evitar

No mezcles Bebas con DM Sans en el mismo nivel jerárquico. No uses Playfair para precios, labels o botones.

Componentes
Botones
6 variantes de botón. Cada una tiene un uso específico — no intercambiar. Al hacer :active, el botón se desplaza 3px hacia abajo-derecha para simular presión.
Primary — acción principal de pantalla
/* Primary */ background: #d42b2b; border: 1.5px solid #aa1f1f; box-shadow: 4px 4px 0 #aa1f1f; color: white;
Secondary — acción secundaria o de retorno
Black — CTA con énfasis máximo
Ghost / Dashed — agregar, expandir
Mercado Pago — exclusivo para pago
⚠️ Solo usar este botón para redirigir a Mercado Pago. No reutilizar el color azul (#009ee3) para otros elementos del cliente.
✓ Correcto

Una sola acción primaria por pantalla. El botón llena el ancho en CTAs de pantalla completa. El tamaño sm solo en cards.

✕ Evitar

No poner dos botones primary en la misma vista. No usar ghost para acciones destructivas. No cambiar los colores de shadow.
